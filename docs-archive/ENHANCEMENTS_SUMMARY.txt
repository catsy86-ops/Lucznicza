╔════════════════════════════════════════════════════════════════════════════════╗
║                         HOW TO USE THE TOOLBAR                                ║
╚════════════════════════════════════════════════════════════════════════════════╝

1. Open the map (index.html)

2. Look for ⚙️ button at bottom-left corner

3. Three ways to toggle modules:

   Method A: Click the button
   ─────────────────────────
   • Click ⚙️ to expand toolbar
   • Click any module button to toggle
   • Modules show blue highlight when active
   • Count badge updates (0-9)

   Method B: Use keyboard shortcut
   ─────────────────────────────────
   • Make sure map is focused
   • Press E, W, H, R, T, Z, D, N, or Y
   • Module toggles instantly
   • Toast notification appears

   Method C: Programmatic API
   ──────────────────────────
   • MapEnhancementsUI.enableModule('weather')
   • MapEnhancementsUI.disableModule('hazards')
   • MapEnhancementsUI.getStatus()
   • MapEnhancementsUI.toggleModule(key, button)

4. Your preferences are saved automatically

5. Next visit: Your modules will be restored
