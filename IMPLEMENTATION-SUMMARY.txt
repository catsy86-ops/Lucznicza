================================================================================
  TECHNICAL NOTES
================================================================================

ARCHITECTURE:
• Modular design: each feature in separate file
• Non-invasive: uses !important CSS to override conflicts
• Responsive: media queries for all breakpoints
• Accessible: WCAG AA compliance, keyboard navigation
• Performant: fixed positioning (no reflow), CSS transforms (GPU accelerated)

CSS STRATEGY:
• Grid system: map-layout-grid.css (single source of truth)
• Z-index management: ui-fix-overlapping.js (clear hierarchy)
• Component styles: individual modules (pogon-feature.js, etc.)
• Responsive: mobile-first, progressive enhancement

JAVASCRIPT PATTERNS:
• IIFE (Immediately Invoked Function Expression) for modules
• Event delegation for efficiency
• RequestAnimationFrame for animations
• LocalStorage for state persistence
• Deep linking via URL hash

PERFORMANCE:
• Widget positioning: fixed (no document reflow)
• Rendering: CSS transforms (GPU accelerated)
• Updates: event-driven (not polling)
• Animations: 60 FPS target (requestAnimationFrame)
• Memory: ~2-3MB for all widgets
